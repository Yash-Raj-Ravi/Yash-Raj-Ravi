## 📌 Featured Projects

### 🏭 1. Industrial Knowledge Intelligence Platform
> **An AI-powered industrial document intelligence platform combining multi-document RAG and Knowledge Graphs.**
- **Document & OCR Ingestion:** Built multi-document parsing pipelines for technical PDFs and scanned industrial records using `PyMuPDF`.
- **Semantic Search & Source-Cited Q&A:** Engineered a Retrieval-Augmented Generation (RAG) engine backed by `ChromaDB` and `LangChain` to deliver grounded, hallucination-free answers with exact page citations.
- **Knowledge Graph Generation:** Automated entity extraction to map relationships across machinery, maintenance reports, and operational procedures.
- **Full-Stack Architecture:** Exposed inference endpoints via a modular `FastAPI` backend paired with an interactive `Streamlit` operator dashboard.
- **Tech Stack:** `LangChain` • `FastAPI` • `ChromaDB` • `PyMuPDF` • `Streamlit` • `LLMs` • `Knowledge Graphs`

---

### 🛰️ 2. Satellite Image Classification using ResNet50
> **High-accuracy deep learning computer vision pipeline trained on the EuroSAT satellite imagery dataset.**
- **Transfer Learning Architecture:** Designed an end-to-end classification workflow leveraging a pre-trained **ResNet50** backbone tailored for multi-spectral geospatial land-use recognition.
- **Optimization & Regularization:** Applied targeted data augmentation, learning-rate scheduling, and layer fine-tuning to prevent overfitting across 10 distinct terrain classes.
- **Performance Benchmark:** Achieved **98.02% validation accuracy** on the EuroSAT benchmark.
- **Tech Stack:** `Python` • `TensorFlow / Keras` • `ResNet50` • `Computer Vision` • `Deep Learning`

---

### 📺 3. YouTube RAG Chatbot
> **Conversational AI system enabling real-time semantic search and Q&A directly over YouTube video transcripts.**
- **Automated Transcript Pipeline:** Extracts, cleans, and chunks long-form YouTube video transcripts dynamically from video URLs.
- **Vector Indexing & Retrieval:** Generates dense semantic embeddings stored in vector databases (`FAISS`/`ChromaDB`) for fast similarity search.
- **Context-Aware Generation:** Uses `LangChain` retrieval chains to answer user queries strictly based on spoken video content.
- **Tech Stack:** `LangChain` • `Vector Databases` • `OpenAI / Hugging Face Embeddings` • `Python` • `Streamlit`

---

### 🎙️ 4. AI Voice Detection System
> **Acoustic machine learning pipeline designed to detect synthetic and AI-generated human speech.**
- **Signal & Spectral Feature Extraction:** Processed raw audio waveforms to extract key acoustic signatures (MFCCs, spectral centroid, chroma, and zero-crossing rates).
- **Binary Classification Engine:** Trained and evaluated supervised machine learning models to reliably distinguish authentic human voices from deepfake/AI-synthesized audio.
- **Tech Stack:** `Python` • `Scikit-Learn` • `Audio Feature Extraction` • `Machine Learning`
